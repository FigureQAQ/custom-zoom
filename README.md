# 自定义缩放

这是一个 Android 原生小工具，用 Android 系统的无障碍放大功能调整当前屏幕的显示比例。它不读取屏幕帧、不创建虚拟显示、不修改伯索云学堂 APK，也不会申请录屏或投屏授权。无障碍服务启用后会显示一个常驻控制悬浮窗，悬浮窗只包含倍率控制，不绘制屏幕内容。

应用会自动读取平板屏幕比例。用户输入当前屏幕比例和目标视频比例后，应用按下面的公式计算铺满屏幕所需的倍率：

`max(屏幕比例 / 目标比例, 目标比例 / 屏幕比例)`

例如屏幕为 `3:2`、视频为 `4:3` 时，倍率为 `1.125×`。目标比例可以直接输入 `16:9`、`7:5`、`7比5` 或小数，也可以从 `16:9`、`16:10`、`3:2`、`7:5`、`4:3`、`5:4`、`1:1`、`9:16` 预设中选择。

## 构建

使用 Android Studio 打开此文件夹，安装 Android SDK 35 后构建并安装 `app`。最低支持 Android 8.0（API 26）。

## 使用

1. 安装并打开“自定义缩放”，检查自动读取的屏幕比例。
2. 输入目标视频比例，或选择一个常用比例，再选择要打开的课堂应用。
3. 第一次使用时，点击“开启无障碍服务”，在 Android 系统设置中开启“自定义缩放”，然后返回本应用。
4. 在最近任务中锁定“自定义缩放”，并按设备系统的提示允许后台运行，以减少被系统清理的情况。
5. 点击“开始缩放”，应用会打开所选课堂应用并调用系统无障碍放大。
6. 屏幕顶部的悬浮窗可以用“−”“+”按 `0.05×` 微调倍率，点击“停止”恢复原来的屏幕显示，点击倍率文字可重新打开设置。

放大由 Android 系统合成器完成，所以不会出现旧版截图浮层造成的重影、黑屏或 MediaProjection“录制或投放”授权弹窗。倍率作用于当前显示屏，系统会保留屏幕中央并裁切边缘；部分厂商系统可能限制无障碍放大，实际效果取决于平板的 Android 版本和系统实现。

应用不绑定特定平板型号，适用于支持无障碍放大的 Android 8.0 及以上手机和平板；不同厂商的系统设置名称和无障碍实现可能略有差异。
